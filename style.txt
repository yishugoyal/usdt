# RUPEEBRIDGE — PROFESSIONAL UI/UX REDESIGN

## Sky Blue + White Financial Theme

You are a senior product designer and frontend UI engineer specializing in modern fintech applications.

The RupeeBridge platform is already fully implemented.

Your task is **NOT to rebuild the application**.

Your task is to perform a complete **professional UI/UX redesign and frontend visual refinement** while preserving all existing functionality, APIs, business logic, financial calculations, database behavior, authentication, security, provider integrations, order states, and backend architecture.

---

Transform the existing RupeeBridge interface into a:

* Modern

# 4. DESIGN PHILOSOPHY

Follow these principles:

### White space

Use generous spacing.

Avoid cramped layouts.

### Visual hierarchy

Important information should immediately stand out.

### Simplicity

A first-time user should understand the interface without instructions.

### Trust

Financial information must look precise and reliable.

### Friendly

Use soft shapes, subtle shadows and approachable typography.

### Professional

Avoid childish gradients, excessive animations, excessive glassmorphism, neon colors or flashy crypto aesthetics.

---

# 5. GLOBAL DESIGN SYSTEM

Create a centralized design system.

Use CSS variables/design tokens instead of repeatedly hardcoding colors.

Example:

```css
:root {
  --color-primary: #38BDF8;
  --color-primary-dark: #0EA5E9;
  --color-primary-deep: #0369A1;

  --color-primary-soft: #E0F2FE;

  --color-background: #F8FCFF;
  --color-surface: #FFFFFF;

  --color-text: #0F172A;
  --color-text-secondary: #64748B;

  --color-border: #E2E8F0;

  --color-success: #16A34A;
  --color-warning: #F59E0B;
  --color-error: #DC2626;
}
```

All components should use these variables.

Do not scatter random hex colors throughout the application.
